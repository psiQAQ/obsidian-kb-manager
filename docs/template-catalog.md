# 内置知识库模板

每种用途提供两套可独立建库的模板。下面的星数采自 2026-11-21 的 GitHub 仓库 API，反映上游仓库当日的关注度。Researcher 和 Technology Radar 来自同一上游，使用不同的目录与组织方法。
