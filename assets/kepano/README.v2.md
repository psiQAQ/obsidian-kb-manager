# Kepano 个人知识库 · Kepano personal knowledge base

从 [[__KB_ROOT__/Templates/Bases/Everything.base|所有条目 / Everything]] 开始。试试 [[__KB_ROOT__/Categories/Books|书籍 / Books]]、[[__KB_ROOT__/Categories/People|人物 / People]] 和 [[__KB_ROOT__/Categories/Places|地点 / Places]]。

为一本书建记录时，在本库打开空白 Markdown 笔记，运行 **插入本库页面模板**，选择 **Book Template**，预览书籍分类链接后确认。页面模板保存在 Vault 的 Templates 设置目录下的 `Kepano/`，默认是 `Templates/Kepano/`。各库的分类视图保存在各自的 `Templates/Bases/`。

For a new book record, open a blank Markdown note in this library and run **Insert library template**. Select **Book Template**, review the link to this library's Books category, and confirm. Page templates are shared in the `Kepano/` subfolder of the vault's Templates folder. Keep clippings in `Clippings/`, daily notes in `Daily/`, personal notes in `Notes/`, reference entries in `References/`, and local attachments in `Attachments/`. The views in this library's `Templates/Bases/` search its own records.

地图视图需要 Obsidian 支持相应视图类型。地点分类同时提供表格。地图视图不可用时，打开 [[__KB_ROOT__/Templates/Bases/Places.base|地点表格 / Places table]]。
