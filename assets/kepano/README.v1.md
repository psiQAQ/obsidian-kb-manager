# Kepano 个人知识库 · Kepano personal knowledge base

从 [[__KB_ROOT__/Templates/Bases/Everything.base|所有条目 / Everything]] 开始。试试 [[__KB_ROOT__/Categories/Books|书籍 / Books]]、[[__KB_ROOT__/Categories/People|人物 / People]] 和 [[__KB_ROOT__/Categories/Places|地点 / Places]]。为一本书创建笔记时，可从 `Templates/Book Template.md` 复制属性，完成后重新打开书籍分类。

Start with a category or the Everything view. Use the note templates in `Templates/` for new records. Keep clippings in `Clippings/`, daily notes in `Daily/`, personal notes in `Notes/`, reference entries in `References/`, and local attachments in `Attachments/`. Bases in `Templates/Bases/` search this library. Some reference entries are empty starting points for linked people and topics.

地图视图需要 Obsidian 支持相应视图类型。地点分类同时提供表格。地图视图不可用时，打开 [[__KB_ROOT__/Templates/Bases/Places.base|地点表格 / Places table]]。
