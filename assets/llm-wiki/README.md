打开[知识索引](./wiki/index.md)浏览现有知识，打开 [Bases 总览](./knowledge.base)筛选本库页面。

把需要保留的原始文件放在 `raw/`，网页剪藏放在 `Clippings/`，自己的想法写在 `Notes/`。例如，将论文放入 `raw/论文.pdf` 后，可在 `Notes/阅读记录.md` 写下疑问，并链接到原件。整理后的知识页放在 `wiki/`，注明来源，并将入口加入索引。报告放在 `reports/`。

页面样板在本库 `templates/`。复制所需样板到目标目录，按实际情况填写属性和正文。用 Knowledge Base Manager 预览本库变更后保存版本。库内的 [AGENTS.md](./AGENTS.md) 说明内容归属与编辑规则，[kb.toml](./kb.toml) 记录目录映射。
