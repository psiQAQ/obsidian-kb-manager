# 课程学习

先看 [示例课程](./Courses/实验入门/课程索引.md)。每门课的 `Lectures/` 保存课堂讲义，`Assignments/` 保存作业，`Notes/` 保存自己的解释。新建时分别使用 **讲义** 和 **作业** 模板。填写课程链接后，作业改成 `scheduled` 并录入截止日。

启用 [Templater](https://obsidian.md/plugins?id=templater-obsidian)，让它能从模板目录选中 [建立课程结构](./Integrations/建立课程结构.md)。打开本库首页，运行 Templater 的 **Open insert template modal** 并选择该模板，输入课程名。它会创建课程目录和课程索引，再打开索引。中途失败可以用同名重试，已创建的文件继续保留。
