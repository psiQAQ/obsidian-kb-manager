# 项目推进与周期复盘

在 `Projects/` 以 **推进项目** 记录目标和任务。持续承担的责任、通用材料和结项项目分别放进 `Areas/`、`Resources/` 和 `Archives/`。在 [开放日演示](./Projects/开放日演示.md) 看正文任务如何带截止日或周重复规则。

启用 [Tasks](https://obsidian.md/plugins?id=obsidian-tasks-plugin) 与 [Templater](https://obsidian.md/plugins?id=templater-obsidian)。将 [建立本周回顾](./Integrations/建立本周回顾.md) 加进 Templater 可选择的模板目录，打开本库首页，从 **Open insert template modal** 选择该操作，输入 ISO 周（如 `2026-W38`）。周回顾自动显示截至周末的本库未完成任务。只做手动复盘时，可直接插入 **周期回顾** 模板并填写行动。结项后补结果，将笔记移动到 `Archives/`。
