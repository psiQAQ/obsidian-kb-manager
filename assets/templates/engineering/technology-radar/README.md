# 技术雷达

打开 [选型示例](./Radar/本地全文索引.md) 看一次试用如何进入决策。一条记录对应一个工具或方法。用 **技术条目** 写适用场景、反对理由和替代方案。

按阶段视图依次显示评估（`assess`）、小范围试用（`trial`）、采用（`adopt`）和暂缓（`hold`）。改变状态时给 `history` 添加一行，如 `2026-09-08 trial`，并在正文保留当时的依据。采用时填写 `adoption_reason`。
