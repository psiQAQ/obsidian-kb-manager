# 知识花园

把未弄懂的窍门写到 [示例种子](./Seeds/检索词怎么选.md) 同一类的 **种子** 里；试过一次，就把过程、环境和失败条件写为 **经验条目**。学习顺序需要串联时，给经验补上相邻条目链接。

想分享时把 `maturity` 置为 `evergreen`、`publish_ready` 置为 `true`，再运行体检。将可分享的内容标为 `visibility: public`，将只用于自己或团队的内容标为 `visibility: private`。桌面检查按 Obsidian 实际打开的页面核对属性。离线检查遇到短链等无法确定目标的引用时会标为待核实。本库的准备队列仅列出候选内容，由你另行选择发布方式。
