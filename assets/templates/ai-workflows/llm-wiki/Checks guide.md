# 知识页索引与分析证据

在本库 `wiki/` 下用知识页模板建一页。将 `managed_by` 设为 `agent`，在索引中添加指向该页的相对 Markdown 链接，并填写一句摘要。这样索引覆盖检查可以识别它。

在另一个子目录创建同名知识页。此时第一条链接只收录第一篇。把第二页的链接放入代码块或行内代码也只是在展示写法，仍会提示未收录。把链接添加为索引正文后提示消失；人工笔记和初始空综述继续按各自用途保留。

把一篇 Agent 管理的知识页标成 `type: analysis`，在 `sources` 填入实际使用的资料路径。清空来源后，专项检查会要求人工核对。现有体检继续核对链接和原文等项目。
