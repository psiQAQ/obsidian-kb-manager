# AI 协作工作记忆

开始一轮工作前，打开 [工作卡](./Work/整理资料入口.md) 和上次的交接，核对能访问的资料与当前决定。结束时用 **会话交接** 记录变更、未验证之处和下一步，使用 `work` 链接回工作卡。需要在后续继续沿用的决定写进 **决定**，把新决定的 `supersedes` 指向旧决定。保留旧页，以便下次追溯为什么改变。

可以让代理按 [操作约定](./AGENTS.md) 读写明确选定的本库笔记。处理工具输出或聊天随手记录时，先摘取推进任务所需的信息，并确认适合写入库。
