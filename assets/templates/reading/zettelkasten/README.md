# 卡片盒

先把没想清的事写进 [闪念](./Fleeting/看懂还是能解释.md)。读过一份材料后，用 **文献卡** 写下来自它的观点和位置。把能独立解释的一条想法改写为 **永久卡**。

考虑从哪读起、卡片如何相互补充时，用 **结构卡** 编排。输出前可用 **项目卡** 暂存某篇文章要用的一组卡片。试着由 [学习方法结构页](./Structure/学习方法.md) 找到永久卡及其来由。
