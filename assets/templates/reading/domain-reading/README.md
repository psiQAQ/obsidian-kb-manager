# 领域阅读与间隔复习

从 [实验设计主题](./Topics/实验设计.md) 开始，依序进入术语和阅读事项。新建 **主题入口**，写清想解决哪个问题；把材料登记在 **阅读项**，读后产出一张 **术语**。

启用 [Spaced Repetition](https://obsidian.md/plugins?id=obsidian-spaced-repetition)，保留默认多行问答分隔符 `?`。在本库每张卡使用 `#flashcards/<本库卡组名>` 标签，选择独立组名后将模板中的示例组名改成它。运行插件的 **Review flashcards** 并选择该组。`review` 供本库视图和检查使用，实际调度状态由复习插件记录。
