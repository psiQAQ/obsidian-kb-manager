# 日记与知识札记

当天经过写进 `Journal/`，使用 **日记**。需要反复引用的发现写进 `Notes/`，使用 **札记**，并和哪一天想到它互链。

启用 [Templater](https://obsidian.md/plugins?id=templater-obsidian) 后，把 [归档当前札记](./Integrations/归档当前札记.md) 加入 Templater 可选择的模板目录。打开一个直接位于本库 `Notes/` 的札记，运行 Templater 的 **Open insert template modal** 并选择该操作。它按 `date` 移入本库对应年份目录。你也可直接创建年度目录，使用 Obsidian 的移动命令归档。
