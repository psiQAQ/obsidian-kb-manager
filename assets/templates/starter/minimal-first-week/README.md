# 首周笔记

打开 [日记入口](./Journal/2026-09-07.md)，看看一条记录如何结尾。接着在 `Journal/` 新建 `YYYY-MM-DD.md`，插入 **每日记录**。写一件观察、一条待跟进的事。留下这条日记后，可以把首页的日记入口更新为你的日记。

三天后，为反复出现的问题建一页，用 `[[` 从当天日记链接过去。第七天用 **首周回顾** 写下你想继续记什么。
