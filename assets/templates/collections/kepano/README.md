# Kepano 个人知识库 · Kepano personal knowledge base

从 [[./Templates/Bases/Everything.base|所有条目 / Everything]] 开始。试试 [[./Categories/Books|书籍 / Books]]、[[./Categories/People|人物 / People]] 和 [[./Categories/Places|地点 / Places]]。

为一本书建记录时，在本库打开空白 Markdown 笔记，运行 **插入本库页面模板**，选择 **Book Template**。核对预览中的书籍分类链接，确认插入后打开书籍分类查看。页面模板保存在本库 `Templates/`，分类视图保存在本库 `Templates/Bases/`。

For a new book record, open a blank Markdown note in this library and run **Insert library template**. Select **Book Template**, review the link to this library's Books category, and confirm. Keep clippings in `Clippings/`, daily notes in `Daily/`, personal notes in `Notes/`, reference entries in `References/`, and local attachments in `Attachments/`. Page templates live in this library's `Templates/` and the views in `Templates/Bases/` search its own records.

地图视图需要 Obsidian 支持相应视图类型。地点分类同时提供表格。地图视图不可用时，打开 [[./Templates/Bases/Places.base|地点表格 / Places table]]。

用 **App Template** 记录应用时，应用会通过属性中的链接关联到本库 [Apps](./References/Apps.md) 索引。在 Apps 页的反向链接中查看关联应用。
